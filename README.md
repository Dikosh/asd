# Jolda — биржа грузов и транспорта

Платформа, где заказчики и перевозчики находят друг друга напрямую: размещают грузы и транспорт, откликаются, договариваются в чате и ведут рейс с GPS на карте. Интерфейс на русском, казахском и английском, рассчитан на телефон и компьютер.

Продукт собран по двум исходным документам («Функциональное описание платформы для логистики» и «Логистикалық платформаның негізгі функциялары») и закрывает возможности, которые есть у Della и Fa-Fa.kz.

## Запуск

Нужен Node.js 22.13 или новее. База данных — встроенный SQLite, отдельно ставить ничего не надо.

```bash
npm install
npm run build   # собирает интерфейс
npm start       # http://localhost:3000
```

При первом запуске в демо-режиме база заполняется примерами: 16 компаний, около 65 объявлений, история рейсов с отзывами и активный рейс с GPS-треком. На экране входа есть кнопки «Демо-доступ» — вход одним нажатием под заказчиком, перевозчиком, логистом, брокером, водителем или модератором.

Для разработки: `npm run dev` (API на :3000, интерфейс с горячей перезагрузкой на :5173).

В Docker:

```bash
docker build -t jolda .
docker run -p 3000:3000 -v jolda-data:/data -e DEMO_MODE=1 jolda
```

## Что умеет

| Раздел | Возможности |
| --- | --- |
| Вход | По номеру телефона и коду из SMS; регистрация одной формой: ФИО, почта, компания (ИП/ТОО), роль |
| Роли | Заказчик, Перевозчик, Логист, Брокер, Водитель — от роли зависят рекомендации на главной |
| Объявления | Размещение в 4 шага: маршрут с промежуточными пунктами, 31 тип кузова, вес, объём, способ погрузки, класс ADR, документы TIR / CMR / ЕКМТ / T1, даты, ставка и условия оплаты; статусы «Активные», «Закрытые», «Архив»; счётчик просмотров, поднятие в топ, «Поделиться» |
| Поиск | Город и радиус, страна, даты, кузов, груз, вес, объём, погрузка, ставка, валюта, оплата, документы; «только проверенные», «только прямые», «только партнёры», «новые за сутки», ADR, международные; сортировка; список и карта |
| Подписки | Сохранённый поиск с колокольчиком: о новом подходящем объявлении приходит уведомление — в приложении и push на телефон |
| Отклики и чат | Отклик с предложением цены, чат в реальном времени, принятие и отклонение |
| Рейсы | Этапы пути, обязательная передача GPS с телефона водителя, живая карта у заказчика, ссылка для получателя без регистрации, заявка на перевозку для печати, обязательный отзыв |
| Проверка компаний | Контрольный разряд БИН/ИИН, документы и фото с удостоверением, модерация, рейтинг по отзывам, зелёный и красный индикаторы, общий чёрный список с причиной и отзывом, жалобы модератору |
| Отношения | Партнёры (метка и фильтр) и личный список скрытых компаний |
| Команда | Владелец приглашает сотрудников и водителей по номеру телефона — у каждого свой вход |
| Цены | Статистика ставок по направлениям и типам кузова; подсказка «выше или ниже рынка» в объявлении |
| Инструменты | Расстояние и стоимость рейса с маршрутом на карте, нагрузка на оси, курсы Национального банка |
| Работа | Вакансии владельцев транспорта и резюме водителей, кнопка «В сотрудники» |
| Помощь | Вопросы и ответы, правила безопасности, справка по документам, новости, обращение в поддержку |
| Кабинет | Профиль и документы, отклики, сообщения, рейсы, машины, команда, сотрудники, баланс и тариф, каталог компаний, партнёры, чёрный список, настройки |
| Модератор | Сводка по платформе, проверка компаний и документов, жалобы, обращения, новости |

### Чем сильнее конкурентов

- **Подбор «по пути».** Машина находится, даже если города заказчика — промежуточные точки её маршрута; под каждое объявление платформа сама подбирает встречные и показывает процент совпадения.
- **GPS привязан к сделке и не требует трекера.** Рейс создаётся из принятого отклика; позицию передаёт телефон водителя, экран при этом не гаснет. Без включённого GPS рейс не начать.
- **Контакты бесплатны.** Платные только дополнительные возможности: поднятие в топ и тариф Pro.
- **Репутация до сделки.** Индикатор, отзывы, документы и чёрный список видны прямо в отклике; о рискованном контрагенте платформа предупреждает.
- **Отзыв нельзя пропустить** — рейтинг складывается только из настоящих рейсов.
- **Работает как приложение без магазина.** Сайт ставится на главный экран телефона и присылает push-уведомления.

## Что подключается отдельно

Эти части зависят от внешних договоров и ключей, поэтому в коде сделаны точки подключения, а не имитация:

| Что | Сейчас | Как подключить |
| --- | --- | --- |
| SMS | В демо-режиме код показывается на экране входа; без демо — пишется в лог сервера | `SMS_WEBHOOK_URL` и `SMS_WEBHOOK_TOKEN`: сервер отправит `POST {phone, text}` (см. `server/sms.js`) |
| Онлайн-оплата | Пополнение баланса работает только в демо-режиме | Подключить платёжного провайдера в `POST /api/balance/topup` |
| Дороги | Расстояние — оценка: прямые отрезки с дорожным коэффициентом 1,22 | `OSRM_URL` — адрес сервера маршрутизации OSRM: расстояние и линия маршрута станут дорожными |
| ЕСУТД | У сотрудника вручную отмечаются статус и номер договора | Автосверка — после получения доступа к API esutd.gov.kz |
| GPS в фоне | Позиция передаётся, пока Jolda открыта на телефоне водителя | Фоновая передача требует приложения из магазина или трекера в машине |
| Магазины приложений | Сайт устанавливается на главный экран (PWA) | Для Google Play сайт упаковывается в Trusted Web Activity; для App Store нужна отдельная сборка |

## Настройки

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт сервера |
| `DATA_DIR` | `./data` | Папка с базой, загруженными документами и ключами push |
| `DEMO_MODE` | включён, если `NODE_ENV` не `production` | Демо-данные, вход одним нажатием, код на экране, демо-пополнение |
| `SMS_WEBHOOK_URL`, `SMS_WEBHOOK_TOKEN` | — | Отправка кодов входа через вашего SMS-провайдера |
| `OSRM_URL` | — | Сервер маршрутизации OSRM для расстояний по дорогам |
| `PUSH_CONTACT` | `mailto:support@jolda.local` | Контакт владельца сервиса для push-серверов браузеров |

Перед боевым запуском выключите демо-режим (`DEMO_MODE=0`), подключите SMS и назначьте модератора (поле `is_admin` в таблице `users`). Push-уведомления и геолокация работают только по HTTPS.

## Устройство

```
server/           API на Express, SQLite через встроенный node:sqlite
  routes/         auth, listings, deals (отклики, чат, рейсы), company (кабинет), extras (уведомления, команда, тариф, инструменты)
  geo.js          справочник мест, расстояния, подбор «по пути», проверка БИН
  data/places.json  города и посёлки (собирается из GeoNames скриптом scripts/build-places.py)
  notify.js, i18n.js  уведомления и их тексты на трёх языках
  seed.js         демо-данные
web/src/          интерфейс на React и TypeScript, карта на Leaflet
  pages/          экраны
  kz.ts, en.ts    переводы (ключ — русская строка)
web/public/sw.js  сервис-воркер для push-уведомлений
tests/            сквозные тесты API
```

Обновления в реальном времени (сообщения, отклики, уведомления, позиция машины) идут через Server-Sent Events.

```bash
npm test                  # сквозные тесты API
npm run i18n              # проверка, что у каждой строки есть казахский перевод
npm run seed -- --reset   # очистить базу и загрузить демо-данные заново
python3 scripts/build-places.py   # пересобрать справочник мест
```

Справочник мест построен на данных [GeoNames](https://www.geonames.org/) (лицензия CC BY 4.0). Карта — © участники OpenStreetMap.
