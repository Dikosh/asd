# Jolda — биржа грузов и транспорта

Платформа, где заказчики и перевозчики находят друг друга напрямую: размещают грузы и транспорт, откликаются, договариваются в чате и ведут рейс с GPS на карте. Интерфейс на русском и казахском, рассчитан на телефон и компьютер.

Продукт собран по двум исходным документам: «Функциональное описание платформы для логистики» и «Логистикалық платформаның негізгі функциялары» (преимущества перед FAFA KZ).

## Запуск

Нужен Node.js 22.13 или новее. База данных — встроенный SQLite, отдельно ставить ничего не надо.

```bash
npm install
npm run build   # собирает интерфейс
npm start       # http://localhost:3000
```

При первом запуске в демо-режиме база заполняется примерами: 16 компаний, около 65 объявлений, история рейсов с отзывами и один активный рейс с GPS-треком. На экране входа есть кнопки «Демо-доступ» — вход одним нажатием под заказчиком, перевозчиком, логистом, брокером, водителем или модератором.

Для разработки: `npm run dev` (API на :3000, интерфейс с горячей перезагрузкой на :5173).

В Docker:

```bash
docker build -t jolda .
docker run -p 3000:3000 -v jolda-data:/data -e DEMO_MODE=1 jolda
```

## Что умеет

| Раздел | Возможности |
| --- | --- |
| Вход | По номеру телефона и коду из SMS; регистрация одной формой: ФИО, почта, компания (ИП/ТОО), роль |
| Роли | Заказчик, Перевозчик, Логист, Брокер, Водитель — от роли зависят рекомендации на главной |
| Главная | Информация о платформе, активный рейс, рекомендуемые грузы или транспорт |
| Мои грузы / Мои машины | Размещение в 4 шага (маршрут с промежуточными пунктами → характеристики → даты и оплата → описание); списки «Активные», «Закрытые», «Архив»; поднятие в топ |
| Найти груз / транспорт | Все фильтры из описания, радиус от города, сортировка, сохранённые поиски, вид списком и на карте, подсказка «Как пользоваться фильтром» |
| Карточка объявления | Позвонить, WhatsApp, рейтинг компании, меню «Действия»: открыть, отметить, заметка, скрыть |
| Отклики и чат | Отклик с предложением цены, чат в реальном времени, отзыв отклика, принятие и отклонение |
| Рейсы | Этапы пути, обязательная передача GPS перевозчиком, живая карта у заказчика, оценка оставшегося пути, обязательный отзыв после завершения |
| Кабинет | Профиль и документы, отклики, сообщения, рейсы, машины, сотрудники, баланс, каталог компаний, настройки |
| Проверка компаний | Контрольный разряд БИН/ИИН, загрузка документов, модерация, рейтинг по отзывам, зелёный и красный индикаторы |
| Чёрный список | Отдельное окно: у каждой записи причина и отзыв |
| Работа | Вакансии владельцев транспорта и резюме водителей, связь по телефону или в WhatsApp, кнопка «В сотрудники» |

### Чем сильнее обычной доски объявлений

- **Подбор «по пути».** Машина находится, даже если города заказчика — промежуточные точки её маршрута. Под каждое активное объявление платформа сама подбирает встречные по маршруту, датам, весу, объёму и кузову и показывает процент совпадения.
- **GPS привязан к сделке.** Рейс создаётся из принятого отклика; без включённого GPS перевозчик не может начать рейс и не может выключить его в пути.
- **Ссылка для получателя.** Рейс виден на карте без регистрации — и без телефонов сторон.
- **Рыночный ориентир ставки.** В карточке видно, выше или ниже рынка ставка за километр.
- **Репутация до сделки.** Индикатор, отзывы, документы и записи чёрного списка видны прямо в отклике; о рискованном контрагенте платформа предупреждает.
- **Отзыв нельзя пропустить.** Пока отзыв о завершённом рейсе не оставлен, нельзя размещать объявления и откликаться.
- **Брокер в один шаг.** У международных перевозок есть переход к проверенным таможенным брокерам.

## Что подключается отдельно

Эти части зависят от внешних договоров и ключей, поэтому в коде сделаны точки подключения, а не имитация:

| Что | Сейчас | Как подключить |
| --- | --- | --- |
| SMS | В демо-режиме код показывается на экране входа; без демо — пишется в лог сервера | `SMS_WEBHOOK_URL` и `SMS_WEBHOOK_TOKEN`: сервер отправит `POST {phone, text}` (см. `server/sms.js`) |
| Онлайн-оплата | Пополнение баланса работает только в демо-режиме | Подключить платёжного провайдера в `POST /api/balance/topup` |
| ЕСУТД | У сотрудника вручную отмечаются статус и номер договора | Автосверка — после получения доступа к API esutd.gov.kz |
| Дороги | Расстояние считается по прямым отрезкам с дорожным коэффициентом 1,22 | Подключить маршрутизатор (например, OSRM) в `server/geo.js` |
| Города | Справочник из 85 городов Казахстана и соседних стран | Расширить `server/geo.js` или подключить геокодер, чтобы принимать посёлки |
| GPS в фоне | Позиция передаётся, пока приложение открыто на телефоне водителя | Фоновая передача требует мобильного приложения или GPS-трекера в машине |

## Настройки

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт сервера |
| `DATA_DIR` | `./data` | Папка с базой и загруженными документами |
| `DEMO_MODE` | включён, если `NODE_ENV` не `production` | Демо-данные, вход одним нажатием, код на экране, демо-пополнение |
| `SMS_WEBHOOK_URL`, `SMS_WEBHOOK_TOKEN` | — | Отправка кодов входа через вашего SMS-провайдера |

Перед боевым запуском выключите демо-режим (`DEMO_MODE=0`), подключите SMS и назначьте модератора (поле `is_admin` в таблице `users`).

## Устройство

```
server/           API на Express, SQLite через встроенный node:sqlite
  routes/         auth, listings, deals (отклики, чат, рейсы), company (кабинет)
  geo.js          города, расстояния, подбор «по пути», проверка БИН
  seed.js         демо-данные
web/src/          интерфейс на React и TypeScript, карта на Leaflet
  pages/          экраны
  kz.ts           казахский перевод (ключ — русская строка)
tests/            сквозной тест API: от регистрации до отзывов
```

Обновления в реальном времени (сообщения, отклики, позиция машины) идут через Server-Sent Events.

```bash
npm test        # сквозные тесты API
npm run i18n    # проверка, что у каждой строки есть казахский перевод
npm run seed -- --reset   # очистить базу и загрузить демо-данные заново
```
